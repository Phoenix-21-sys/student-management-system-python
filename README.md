# Student Management System using Python

A menu-driven Student Management System built using Python packages and modular programming.

## Features
- Add and display student details
- Search for students
- Calculate marks and results
- Calculate attendance percentage
- Check exam eligibility

## Concepts Used
- Python functions
- Dictionaries
- Modules and packages
- Modular programming
- Conditional statements and loops

## Project Structure

student-management-system-python/
- main.py
- student_utils/
  - __init__.py
  - student.py
  - marks.py
  - attendance.py
  - result.py

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   python main.py
